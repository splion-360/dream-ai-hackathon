# Dream AI Math Tutor

The repository is split by application surface:

- `backend/` — FastAPI, model generation, Manim rendering, evaluation data, and tests.
- `frontend/` — reserved for the upcoming web application.
- `docs/` — local design and research material; only `.gitkeep` is tracked.

See [`backend/README.md`](backend/README.md) for setup, development, and verification commands.
